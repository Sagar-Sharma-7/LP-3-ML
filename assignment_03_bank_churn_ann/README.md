# Assignment 3 Bank Churn Neural Network

Run `py run_assignment.py --download`, or copy `Churn_Modelling.csv` to `data/` and run without `--download`.

This uses a scikit-learn multilayer perceptron (an ANN), standardizes numeric values, one-hot encodes categories, applies early stopping, and saves an accuracy score, confusion matrix, and neural-network loss curve.
