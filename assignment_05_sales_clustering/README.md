# Assignment 5 Sales Clustering

Run `py run_assignment.py --download`, or copy `sales_data_sample.csv` into `data/` and run without `--download`.

The program uses sales, quantity, price, MSRP and date features; creates an elbow graph, determines a cluster count objectively using silhouette score, runs K-Means and hierarchical clustering, and saves all figures plus a paste-ready result.
